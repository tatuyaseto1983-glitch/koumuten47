# 全国人口・世帯データ取得ツール（e-Stat API）

政府統計の総合窓口（e-Stat）のAPIから、**全国計・47都道府県・約1,900市区町村**の
人口関連データをまとめて取得します。住宅・リフォーム・民泊事業の市場規模を
エリアごとに比べるための、元データづくりが目的です。

## 1. 準備：アプリケーションID（appId）

e-Stat APIは登録者ごとのIDが必須です。無料で、5分ほどで発行できます。

1. ユーザ登録 → https://www.e-stat.go.jp/mypage/user/preregister
2. ログイン → マイページの「API機能（アプリケーションID発行）」
3. 名称は任意、URLは公開サイトで使わないなら `http://test.localhost/` を入力して発行

発行されたIDを環境変数に入れます。

```bash
export ESTAT_APPID="発行されたID"        # macOS / Linux
setx ESTAT_APPID "発行されたID"          # Windows（PowerShell、設定後に再起動）
```

## 2. インストール

```bash
pip install -r requirements.txt
```

## 3. 使い方

```bash
# 1. 都道府県のデータを取得
python3 scripts/estat_fetch.py fetch --area-level national,pref

# 2. 市区町村のデータを取得（約1,900自治体。5分ほどかかります）
python3 scripts/estat_fetch.py fetch --area-level city

# 3. 将来推計人口を社人研サイトから取り込む
python3 scripts/ipss_fetch.py

# 4. 集計してレポートを作る
python3 scripts/build_summary.py
python3 scripts/build_report_data.py
python3 scripts/build_report.py     # → reports/national_population_report.html
```

そのほかの使い方:

```bash
# 設定済みの全指標をまとめて取得
python3 scripts/estat_fetch.py fetch-all

# 指標を絞って取得
python3 scripts/estat_fetch.py fetch --indicator population,households

# 都道府県までに限定して軽く回す
python3 scripts/estat_fetch.py fetch --indicator population --area-level national,pref

# 指標CSVを1本の分析用テーブルにまとめる
python3 scripts/estat_fetch.py build
```

統計表を探す・項目コードを確かめるとき:

```bash
python3 scripts/estat_fetch.py search --keyword "社会・人口統計体系 市区町村データ"
python3 scripts/estat_fetch.py meta --table-id 0000010102
```

使用する統計表IDは `config/indicators.json` の `meta.table_map` に控えてあります。
市区町村は「廃置分合処理済」の表を使い、合併による見かけ上の増減が入らないようにしています。

指標の追加や絞り込みは `config/indicators.json` を編集します。
`enabled: false` の指標は `fetch-all` では取得しません。

### 粒度についての注意

- **消費支出**は市区町村別の公表がありません。都道府県庁所在市が最小単位です。
- **将来推計人口**は e-Stat API に収載がないため、社人研サイトのExcelを
  `scripts/ipss_fetch.py` で直接取り込みます。福島県の13市町村は「浜通り地域」として
  一括で推計されており、個別の値がありません（対象は1,904市区町村）。

## 5. 出力されるファイル

```
data/raw/        取得した生JSON（再実行時のキャッシュ、Git管理外）
data/ipss/       社人研からダウンロードしたExcel（Git管理外）
data/processed/  指標ごとのCSV（Git管理外。合計70MB超のため）
  summary_pref.csv   全国＋47都道府県の主要指標（Git管理）
  summary_city.csv   1,913市区町村の主要指標（Git管理）
  summary.json       上記2つをまとめたもの（Git管理）
reports/         配布用のHTMLレポート
```

指標ごとの明細CSVは容量が大きいためGitに含めていません。
`fetch` を再実行すれば同じものが作れます。

CSVは1行1数値の縦持ち形式です。列は以下のとおりです。

`indicator, indicator_label, area_code, area_name, area_level, pref_code,
pref_name, time_code, year, cat_code, cat_name, unit, value, value_raw`

- `area_level` は `national` / `pref` / `city` のいずれかです。
- 秘匿・非該当（`-` や `…`）は `value` が空、`value_raw` に元の記号が残ります。

## 6. 統計表IDの自動解決について

統計表IDは改廃されることがあるため、`config/indicators.json` の `table_id` は
空にしてあります。実行時にキーワードで検索し、選んだ表を
`config/resolved_tables.json` に記録します。意図した表かどうかは、同ファイルの
`candidates`（上位10件）で確認できます。違う表が選ばれていたら、
`table_id` に正しいIDを直接書き込んでください。

## 7. 実行時の作法

e-Stat APIの利用規約第8条で「短時間における大量のアクセス」が禁止されています。
本ツールは既定でリクエスト間隔を2秒空け、1回のリクエストで最大10万件を
まとめて受け取ることで、呼び出し回数を抑えています。間隔は `--sleep` で変更できます。

取得した生JSONは `data/raw/` に残るため、2回目以降は通信せずに再集計できます。
最新値で取り直したいときは `--no-cache` を付けます。

## 8. レポート

`reports/national_population_report.html`（住宅市場コンパス）が成果物です。
1ファイルで完結するアプリで、ブラウザで開けばそのまま使えます。

上部の選択欄で**全国・47都道府県・1,913市区町村**を切り替えると、
9つのタブ（概要／着工／住宅ストック／人口・世帯／人の動き／家計／働く人／
ランキング／出典）の中身がすべてその地域の数字に入れ替わります。
選んだ地域はブラウザに記憶されます。

「人の動き」タブでは、その地域にどの市町村から人が来て、どの市町村へ出て行ったかを
相手先ごとに並べます。政令市は市全体でまとめ、階層が重ならないよう
統計表のレベル情報（都道府県／市町村／区）で選別しています。

家計調査と賃金は都道府県までの公表のため、市区町村を選んだときは
その県の数字を表示し、画面上にその旨を出しています。内容を変えるときは
`reports/report_template.html` を編集して `python3 scripts/build_report.py` を実行します。

数値はすべて取得したCSVから流し込んでいるため、データを取り直せばレポートも更新されます。

### 狙い目スコアについて

市区町村の「狙い目スコア」は公的な統計値ではなく、需要と供給の差を見るために
こちらで計算した目安です。

```
スコア ＝ 転入超過（世帯1,000あたり）− 着工戸数（世帯1,000あたり）
```

人の流入に対して住宅供給が追いついていないほど大きくなります。
散布図の4区分は、全市区町村の中央値を境目にしています。

### 転入元・転出先の扱い

住民基本台帳人口移動報告の統計表は「移動前の住所地（行）× 移動後の住所地（列）」という
形をしています。地域は階層になっていて、そのまま合計すると二重に数えてしまいます。

| レベル | 中身 |
| --- | --- |
| 1 | 総数（前住地） |
| 2 | 都道府県 |
| 3 | 市町村（政令市は市全体） |
| 4 | 政令市の区 |

`scripts/estat_flow_fetch.py` が地域一覧（レベル付き）も書き出すので、
集計時はレベルをそろえて取り出しています。

転入者数・転出者数の合計は、この表と社会・人口統計体系とで対象範囲が異なります
（県内移動を含むかどうか）。アプリの数字は社会・人口統計体系に統一し、
相手先の内訳だけを移動報告から取っています。
